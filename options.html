Görünüm ve Deneyim

Dil Arayüz dilini seçin.
Şu An Çalıyor Spotify / YouTube / YT Music'te çalan şarkıyı Roblox sayfasında gösterir ve buradan kontrol etmeni sağlar. Varsayılan kapalı; veri tarayıcından çıkmaz.
Trello panosu Oyun sayfasında kendi Trello panonu canlı gösteren bir panel açar. Açınca panelden API key + token + pano URL'si girilir. Veri tarayıcından çıkmaz; yalnız Trello'ya gider.
Oyun Kodları Oyun sayfalarında o oyunun kodlarını bulup gösterir (küratörlü kaynak + oyun açıklaması + oyunun resmi sosyal kanalları). Resmi kod API'si olmadığından kodlar "doğrulanmamış" etiketlidir.

Otomatik Yeniden Bağlanma

Oyun aniden kapanırsa (crash, kick, network drop) extension bunu tespit edip aynı server'a tek tıkla geri dönmeni sağlar. Service worker arka planda 30sn'de bir presence kontrolü yapar.

Auto-Reconnect Aktif Crash tespiti yapılır ve oyuna girdiğinde Roblox sayfasında modal gösterilir. Kapalıysa hiçbir tespit yapılmaz.
Sistem Bildirimini de Göster Roblox sayfası kapalıyken sağ alt köşede Chrome'un native bildirimi de çıkar. Kapalıysa sadece in-page modal kullanılır (önerilen).
